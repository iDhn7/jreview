csv 데이터 포멧 
=========================================
store_list.csv -업체 목록
업체명, 업체코드, 상권(전북대, 객사...),위도, 경도

store_info.csv -업체 정보 
업체명, 업체코드, 업체카테고리, 주소, 전화번호, 영업시간, 별점, 위도, 경도 
업체사진, 편의성 정보, 주차여부, 


menu.csv - 업체별 메뉴 정보 
업체코드, 메뉴명, 메뉴 카테고리, 메뉴 가격, 메뉴 내용 




review.csv - 리뷰 정보 
업체코드, ID(작성자), 리뷰 내용, 작성일, 평가 카테고리(맛있어요, 아늑해요)
